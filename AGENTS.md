# Инструкции агенту при выполнении работ

## Не теряй цели проекта

При принятии решений на любом этаки анализируй их на предмет соответствия
требований, целей и описания, данных в [README.md](./README.md)

## Выполняй по этапу за раз 

За один раз выполняй только один этап

## Отчитывайся о работе по каждому этапу

Создавай в каталоге с описением этапа файл Report.md в котором пиши отчет о
проделанной работе.

В конце отчета необходимо указать стоимость генерации в виде:
- Общее число токенов (общая стоимость в USD)
- Число входящих токенов мимо кэша (стоимость в USD)
- Число закешированных входящих токенов (стоимость в USD)
- Число исходящих токенов (стоимость в USD)

## Придерживайся формата

1. **Скелет проекта**
   - Таблица параметров: габариты рамы, оси, высоты, диаметры, посадки, зазоры, ход, толщины.
   - Базы и оси: ось привода, оси направляющих, плоскость стола, плоскость подстолья.
   - Все отверстия и центры подшипников привязываются к этим базам, а не к «пикселям».

2. **Детали как параметрические тела**
   - CadQuery/build123d или FreeCAD: `Box`, `Cylinder`, `revolve`, `sweep`, `fillet`, `chamfer`, `shell`, `hole`, массивы.
   - Отдельно: рама (сварная), стол, накладка, кулачки, кронштейн, ось, балки, опоры, подстолье, хомуты, переходник.
   - Покупные: 6200, LMF10UU, пружины, крепёж — вставляются как готовые тела с посадочными размерами.

3. **Сборка и проверки**
   - Сопряжения: соосность, плоскости, зазоры, ход 3…10 мм, контакт ролика с кулачком, длина пружины, положение дрели.
   - Числовые проверки: bounding box, пересечения, масса, расстояние между отверстиями, зазор в подшипниках, минимальная стенка.
   - Визуальные проверки: рендеры из Blender в нескольких ракурсах, а не «на глаз по SVG».

4. **Выходные файлы**
   - `STEP` — сборка и детали для правки/фрезеровки.
   - `STL/3MF` — печатные детали, каждая отдельно, с ориентацией.
   - `PDF/SVG/DXF` — чертежи, **спроецированные из модели** (FreeCAD TechDraw или HLR в CadQuery/OCP).
   - `CSV` — спецификация и параметры печати.

Эскизы и чертежа, если требуется по задаче, делать в SVG на основе моделей


Файлы размещай в подкаталогах этапа

- pic - растровые изображения
- fig - векторные изображения
- cad - 3D и файлы для производства

## Предлагай 

Если требования или описание конструкции входят в противоречие - предлагай 
изменения конструкции.

## Спрашивай

Все дополнительные вопросы, заданные для уточнения задачи должны быть записаны
в файле Interview.md каталога с описанием этапа

## Учись на ошибках

При работе над этапом прочти всё README.md, Report.md и Interview.md предыдущих
этапов и делай с учетом этой информации.

## Не делай слишком детальные модели

При моделировании процессов избегай слишком жадных алгоритсмов с большим числом
итераций

## Не подглядывай

Не испотльзуй git ни для чтения истории ни для записи.
