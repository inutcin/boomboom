# Инструкции агенту при выполнении работ

## Не теряй цели проекта

При принятии решений на любом этаки анализируй их на предмет соответствия
требований, целей и описания, данных в [README.md](./README.md)

## Выполняй по этапу за раз 

За один раз выполняй только один этап

## Отчитывайся о работе по каждому этапу

Создавай в каталоге с описением этапа файл Report.md в котором пиши отчет о
проделанной работе.

В конце отчета необходимо указать стоимость генерации в виде:
- Общее число токенов (общая стоимость в USD)
- Число входящих токенов мимо кэша (стоимость в USD)
- Число закешированных входящих токенов (стоимость в USD)
- Число исходящих токенов (стоимость в USD)

## Придерживайся формата

- векторные изображения создавай в формате svg и клади их в подкаталог fig
  каталога с описанием этапа
- дублируй векторные изображения растровыми с аналогичным именем в формате png
  и клади из в подкаталог pic подкаталога с описанием этапа

## Предлагай 

Если требования или описание конструкции входят в противоречие - предлагай 
изменения конструкции.

## Спрашивай

Все дополнительные вопросы, заданные для уточнения задачи должны быть записаны
в файле Interview.md каталога с описанием этапа

## Учись на ошибках

При работе над этапом прочти всё README.md, Report.md и Interview.md предыдущих
этапов и делай с учетом этой информации.
