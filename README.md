# boomboom  

Пример проектирования механического устройства от идеи до сборочного чертежа при
помощи DeepSeek и Opencode

## Цель проекта

На основе представленного эскиза с общей идеей спроектировать механическое
устройтво.

### Назначение устройства

Устройство является вибрационным столом, необходимым для проведения физического
эксперимента

### Описание конструкции

1. Устройство выполнено на раме, сваренной из профильной трубы 20мм на 20мм 
толщиной 1.5 мм

2. Геометрически рама можно разделить на 2 части
    - механизм вибростола
        + Стол с вогнутой верхней поверхностью, к которой прикреплены
            - 4 линейшых подшипника, через которые проходят направляющие
            - угловые кронштейны с зажатыми в них через конические гайки и контрагайки 
              подшипниками в качестве роликов
            - потайные болты, крепящие кронштейны через вытянутые регулировочные 
              отверстия в кронштейнах с помощью контрагаек. 
        + Четыре направляющие, проходящие свозь стол и линейные подшипники, по которым 
          стол свободно скользит вверж и вниз. Верхним концом крепятся к раме 
          через соосный боль. Нижним концом к верхней балке фиксации подшипников
          ротора. 
        + Верхние балки фиксации подшипников ротора, к которым так же через 
          соосные болты крепется нижняя часть направляющих и верхняя часть 
          подшипников ротора, заходя в прорезь в балке
        + Нижние балки фиксации подшипников ротора с прорезью для утопления в 
          ней подшипника.
        + Кулачковый механизм
            - Шпилька-ротор - ось механизма
            - Кулачковый диск
            - Подшипники, на которых  крепится в 2 точках
            - Конусные гайки и контрагайки, которыми детали кулачкового 
              механизма фиксируются на оси
        + Четыре прижимные пружины, внутри которых проходит направляющая и которые 
          прижимают сверху к кулачковому диску.
    - Вынос для крепления дрели
        + Фанерное подстолье сверху
        + U-образные хомуты с резьбой для крепления дрели под подстольем
        + Хвостовик шпильки-ротора, который вставляется в патрон дрели.

3. Направляющие, линейные подшипники и прижимные пружины на виде сбоку скрыты за 
рамой. К раме и к балкам фиксации подшипников крепятся торцами с помощью 
нарезанной в них с торцов соосно резьбе

4. Направляющие свободно проходят сквоз стол через отверстия в столе.

5. Снизу к столу на фланцы крепятся линейные подшипники. Сверху на стол давят 
пружины. Без кулачкового диска стол свободно падает по направляющим на верхние 
балки фиксации подшипников.

6. Верхние и нижние балки факсации подшипников имеют прореди для того, чтобы 
подшипники краем ввнешнего кольца заходили в них.

7. Верхние и нижние балки фиксируются на раме с помощью Т-образных соединителей
профильных труб.

8. Верхняя балка крепится при сборке конструкции (к ней крепятся направляющие).
и не перемещается в процессе эксплуатации.

9. Нижняя балка ослабляется и сдвигается вниз, а потом возвращается назад при 
заммене гулачкового механизма, папример при смене кулачкового диска.

10. Кулачковый диск должен быть шире чем подшианики, выполняюшие роль роликов 
и иметь лождинку с закруглёными краями, чтобы ролики по ней катились как по 
направляющей.

12. Ролики на столе собраны следующим образом
    - Через подшипник продет болт с резьбой
    - На резьбе подшипник затягиваетс с двух сторон кническими гайками
    - через отверстие в кронштейне с помощью контрагаек кронштейны-уголки 
      притягиваюттся к коническим гайками
    - и наконец через регулировочные отверстия на другой части крнонштейнов 
      кронштейны крепятся контрагайками снизу к столу потайными болтами.

13. Рама конструкции прдназначена для крепления струбцинами к тяжелой станине или столу
и не эксплуатируется без этого

14. Хвостовик ротора не регулируется по высоте относительно подстолья. Поэтому
    для крепления дрегей с разными диаметрами кожуха можно воспользоваться 
    резиновой подкладкой.

### Требования к устройству

#### Обязательные

1. Амплитуда колебаний должна задаваться конструкционно в диапазоне от 3 до 10
мм.

2. Частота колебания стола регулируемая от 5 до 15 Гц.

3. Характер колебаний - гармонический


#### Желательные

1. Минимальное количество движущихся частей и точек трения

2. Минимальное количество деталей сложной формы, особенно не являющихся фигурами
вращения.

3. Минимальное количество деталей, которые нельзя было бы купить в обычном 
строительном магазине

4. Минимизация нежелательных вибраций подстолья из за переменного радиуса диска.

5. Минимальное количество точек, которыми регулируются частота и амплитуда.

6. Линейное выражение частоты и амплитуды колебаний через геометрические размеры
конструкции
