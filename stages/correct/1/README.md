# Замечания и корретировки по модели. Часть 1.

1. По чертежам не очень понятно устройство крепления роликов, подстолья, 
крепление для дрели к подстолью и крепление кулачкового диска к дрели. 
Необходимо для каждой детали создать изометрическое изображение.

2. Платформа должна быть лёгкой достаточно, чтобы дрель её прокручивала

3. На платформе(столе) будет лежать шарик. Платформа должна быть слегка вогнутой.
Чтобы шарик не слетал с центра, а если слетал, то корректировался.
