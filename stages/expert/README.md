# Инженерная экспертиза

1. Проведи инженерную экспертизу модели, созданной в этапе fix3
2. Сформируй корректировки и замечания, разделив из на 3 части
    - критичные - делающие эксплуатацию невозможной и несущие риск серьёзных
    травм
    - важные - существенно ухудшающие характеристики устройства и несущие
    неудобства при эесплуатации.
    - пожелыния - не несущие прямых рисков, но нежелательные в перспективе.
3. Корректировки и замечания оформи в следующий этап: 
    - каталог fix4 
    - название "Первая корректировка и замечания после инженерной экспертизы", 
    упомяни его в корневом README.md
