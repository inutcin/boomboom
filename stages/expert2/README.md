# Вторая инженерная экспертиза

1. Проведи инженерную экспертизу модели, созданной в этапе fix6

2. Сформируй корректировки и замечания, разделив из на 3 части
    - критичные - делающие эксплуатацию невозможной и несущие риск серьёзных
      травм
    - важные - существенно ухудшающие характеристики устройства и несущие
      неудобства при эесплуатации.
    - пожелыния - не несущие прямых рисков, но нежелательные в перспективе.
3. Корректировки и замечания оформи в следующий этап: 
    - каталог fix4 
    - название "Первая корректировка и замечания после инженерной экспертизы", 
    упомяни его в корневом README.md

фактическое движение 2-лепесткового кулачка не гармоническое (4-я гармоника
0,505 мм, 5,0 % хода для 10 мм; отклонение 5,5 %). Важных замечаний — 23,
пожеланий — 8. В [fix7](../fix7/README.md) выполнены **только параметры
прижимных пружин** (L0=70, Ø12, проволока 1,0); остальные C1–C8, I1–I23,
W1–W8 остаются. Третья экспертиза — [expert3](../expert3/README.md) — проверила
только пружины и контакт ролика.
