# Корректировки и замечания после инженерной экспертизы

## Ответы на вопросы инженерной экспертизы

### Принципиальные вопросы

```
1. Какая именно величина измеряется в эксперименте: вертикальное перемещение, 
ускорение, траектория шарика? Какая точность нужна?
```  

Итого измеряется: время между соударениями (скорее всего микрофоном), частота (скорее всего стробоскопом). Из доп 
параметров будет измеряться коэффициент восстановления после удара 
для теорки. Но это вроде тривиальная задача с микрофоном

```
2. Какой диапазон сочетаний «частота — амплитуда» должен быть 
проверен? Нужны ли все 9 сочетаний 5/10/15 Гц и 3/6/10 мм?
```

Самое важное - параметр w^2 A. Одной амплитуда достаточно. 
Ну то есть на фиксированной амплитуде регулируем чатоту, в через неё w^2 A. Думаю будет хорошим тоном, если это вообще возможно, сделать несколько дисков. на фиксированной амплитуде регулируем чатоту, в через неё w^2 A.

```
3. Какая полезная нагрузка является расчётной: только шарик 33 г или до 5 кг? Как нагрузка распределена и может ли быть смещена от центра?
```

Шарик 33г, другого вроде не планировалось. Нагрузка по центру.

```
4. Какая дрель уже есть/планируется: мощность, обороты, патрон, 
наличие регулятора и фиксации курка? Допустима ли замена на 
мотор-редуктор с частотным приводом?
```

Вообще не шарился в этой теме, буду прям на месте подбирать. Сто процентов нужна фиксация курка, плавный ход курка (иначе как подбирать частоты?)

Устройство крепления необходимо разработать с учетом того, что это может быть любая бытовая дрель с любыми популярными габаритами 
кожуха, патрона, расстояния от патрона до верхушки дрели. 

### Дополнительные вопросы

```
5. Какой ресурс/непрерывность работы и сколько циклов должен выдержать макет?
```

От нескольких секунд до нескольких минут непрерывной работе с кроектной частотой. 

```
6. Какие требования лаборатории к ограждениям, аварийному останову, УЗО, блокировкам и знакам безопасности?
```

Нет особых требований. Достатоно защитного кожуха с выносом ручки управления дрелью за его пределы

```
7. Какой допустимый уровень шума?
```

Не регламентируется

```
8. Какой критерий «гармоничности»: коэффициент нелинейных искажений, допустимая доля высших гармоник, визуальная синусоида? Нужен измеримый допуск.
```

Четких критериев нет, как минимум должны отсутствовать десткие биения, резкие фронты и срезы.

```
9. Допустима ли направляющая стола (линейные подшипники/упругая подвеска), которая добавляет детали и трение? Это конфликт с требованием 4 README.
```

Да. На это можно пойти чтобы убрать возвратную пружину снизу.


```
10. Можно ли убрать нижние пружины и оставить только верхние с регулируемым поджимом?
```

Да, можно.

```
11. Можно ли заменить фанерную верхнюю плиту на стальную и увеличить массу/стоимость?
```

От верхней плиты надо будет отказаться, чтобы исключить удары об неё подскакивающего шарика.

```
12. Можно ли заменить фанерную столешницу на 15 мм или добавить рёбра/локальное усиление?
```

Фанерную столешницу (вибрирующую) заменить распечатанной на 3Д принтере плитой
с вогнутой верхней поверхностью. 
Сверху сделать накладку из железного листа толщиной 0.3-0.5 лист предварительно
обстучать киянкой от центра к краям, чтобы его можно было прижать к верхней 
вогнутой поверхности столешницы. Снизу сделать накладку из 0ю3-0.50.мм стального 
листа. По краям небольшие бортики, саморезами через которые весь пакет собирается 
в общую конструкцию.

```
13. Допустима ли закалка/шлифовка кулачка и изготовление его лазерной/CNC-резкой?
```

Комплект кулачков под разную амплитуду будет распечатан на 3Д принтере. 
Кулачковые диски поэтому должны быть увеличены в толдине до 2 см. 
Соответствующим образом должны быть увеличены и ролики и размеры кронштейнов.

```
14. Нужен ли CAD/STEP и рабочие чертежи или достаточно обновлённых листов и изометрий?
```

Будут нужны позже, когда конструкция и материалы будут согласованы

```
15. Нужен ли тахометр/датчик амплитуды/акселерометр в составе установки или измерения внешние?
```

Измерения внешние

```
16. Есть ли ограничения по габаритам 600 × 500 × 860 мм, массе и стоимости?
```

Да, надо уместиться в эти габариты и массу не более 20 кг. Можно 
увеличить вверх за счет купола - уловителя.

```
17. Можно ли изменить число лепестков кулачка (1/2/4) для оптимизации частоты и амплитуды?
```

Нет, не надо 2 лепеска (овальный кулачок) - оптимально.

```
18. Должен ли шарик быть именно стальным `Ø20`; допускаются ли другой материал/размер и прозрачный колпак?
```

Шарик Может быть от 20 до 33 мм диаметром. 
Другие размеры не допускаются. Вместо прозрачного колпака будет купол-уловитель.

## Изменения конструкции по замечаниям инженерной экспертизы

### Критические замечания

```
- Кожух вокруг кулачка, роликов, патрона/муфты и пружин; стальная сетка + поликарбонат 4…5 мм; блокировка кожуха; аварийный останов; УЗО; знаки.
```

Весь параллепипед установки кроме дна должен иметь кожух из поликарбоната 4-5мм. 
- три боковые стороны кроме той, со стороны которой крепится дрель, должны быть
  закрыты от верха несъёмной в процессе эксперимента пластиной
- верхняя часть стороны с дрелью от верха до подстолья так же должна закрываться
    несъёмнм листом.
- нижняя часть должна закрываться двумя Г-образными дверками с петлён наверху, 
  таким образом, чтобы даже в свободном положении дверцы были закрыты под силой 
  тяжести, оставляя вырез для ручки дрели. Это обеспечит доступ для крепления 
  дрели и смены кулачковых дисков. И должны закрываться на защелку (шпингалет)
- верхняя часть должна закрываться крышкой с петлями для доступа в зону 
  эксперимента (установка шарика) и закрываться на зашелку (шпингалет) 
- опционально дверцы должны иметь прижимные кнопки, которые подают питание 
  на розетку установки только если все двери закрыты за защелки.
- продумать можно ли принудительно включать дрельт только против часовой стрелки
  чтобы принудительно затягивать болты на валу со стандартной правой резьбой

```
- Отдельный вал кулачка на двух подшипниках в жёстком корпусе; упругая муфта к дрели; радиальная нагрузка на патрон — ноль.
```
- в подстолье сделать отверстие прямоугольной формы, а не круглой (щель) ровно 
    такого размера, чтобы проходил кулачковый диск плюс по сантиметру с каждой
    стороны в расчете на точность установки. 
- С подстолья свесить кронштейны, на которых закрепить по подшипнику для оси 
    кулачка
- Валом будет служить резьбовая шпилька, на которой кулачок закрепится с помощью 
    конических гаек и контрагает. Так же шпилька закрепится в подшимниках.
- Вал будет зажиматься в питроне дрели
- Для кронштейнов надо предуспотреть подкладки или шайбы чтобы регулировать 
    высоту свешикания подшипника в зависимости от диаметра кулвчка
- Резиновые подкладки так же стоит предуспотреть под дрель, для регулирования 
    расстояния опи вращения от подстолья в зависимости от диаметра кулачка.

```
- Положительное осевое крепление диска: буртик, два штифта/шпонка, левая резьба или стопорная пластина, резьбовой фиксатор, момент затяжки.
```

Большой момент затяжки + кручение дрели против часовой стрелки.


```
- Антипроворот дрели: стальное седло/хомуты, реактивная тяга, тонкая резина 2…3 мм; проверка вентиляционных окон.
```

- Оставляем U-образные хомуты с затяжкой на кайки и шайбы
- Под верхнюю часть дрели - резиновая подкладка. Она же для регулирования 
    расстояния опи вращения от подстолья

```
- Балансировка диска с оправкой; биение кромки ≤ 0,05 мм.
```

Это вопрос точности изготовления диска

```
- Расчёт пружин: 4 верхние (или 8 с обоснованием), жёсткость, свободная длина, 
диаметр проволоки, материал, напряжение, усталость, критическая частота витков.
```

- Для крепления 4 пружин сверху вместо верхней плиты по бокам сделать 2 балки. 
  которые опустить таким образом, чтобы они были на высоте 10-12 см. от верхней 
  рабочей точки стола. Это позволит
  - уменьшить длину верхних прожин пружин и увеличить их прижимную силу
  - Освободить пространство сверху для возможного подскока шарика на столе
  - увеличить жесткостость подвески стола и уменьшить паразитные боковые колебания
- вмето шпилек использовать направляющие, проходящие через стол и линейные 
  подшипники   

```
- Предподжим с запасом 1,5: не менее 170 Н для 2,6 кг и не менее 480 Н для 7,6 кг (при 15 Гц/10 мм).
```

Допустим

```
- Решение по нижним пружинам: убрать или существенно пересчитать; проверить, что они не отрывают стол от кулачка.
``

Нижние пружины убрать.

```
- Направляющая вертикального перемещения: линейные подшипники/стойки, параллелограммная упругая подвеска или центральная штанга; боковой люфт ≤ 0,1 мм, наклон ≤ 0,1°.
```

Стойки, линейные подшипники. Без центральной штанги.

```
- Ловители/ограничители хода, не позволяющие столу упасть при потере контакта; демпфер.
```

На верхней поверхнсти подстолья элементы из мягкой резины или подушечки.

```
- Стальная верхняя плита 8…10 мм или фанера со стальными прижимными пластинами; болты M8 + штифты к раме; стальные шайбы под гайками; расчёт шпилек.
```

Верхнюю плиту убрать согласно предыдущему пункту об уменьшении и сокращении числа 
пружин. Пружины будут подпираться двумя балками


```
- Раскосы/косынки рамы; анкеровка/резиновые опоры.
```
На нижней части установки (от дна до подстолья) предусмотреть по одной укосине.

### Важные замечания

```
- Выбрать схему: один центральный ролик + направляющая (A ≈ 2e) или два ролика с корректным расчётом `A(e)`.
```

Два ролика

```
- Пересчитать диски: для точных 3/6/10 мм при двух роликах `e ≈ 1,38 / 2,76 / 4,60 мм`; при одном ролике — 1,5/3/5 мм. Проверить, что максимальная амплитуда не превышает 10 мм.
```

Пересчитать диски для двух роликов

```
- Обеспечить регулировку положения кулачка относительно роликов (пазы/шайбы) и осевого положения; процедура настройки по индикатору.
```

- Регулировка по высоте с помощью шайм и подкладок под кронштейны
- регулировка осевого положения - коническими гайками

```
- Критерий гармоничности: THD вертикального ускорения ≤ 5…10 % (уточнить); проверить на макете.
```

Пока не определён

```
- Стабилизация частоты: мотор с замкнутым контуром или дрель с тахометром; плавный пуск/останов; запрет длительной работы вблизи резонанса.
```

Плавный пуск-останов, ручная регулировка оборотов.

```
- Проверить балансировку и биение после сборки.
```

Да

```
- Полная вогнутость рабочей плоскости (эллиптическая/параболическая чаша 5…8 мм) либо наклонный борт к лунке; твёрдая съёмная накладка.
```

Эллиптическая/параполическкая. Распечатана на 3Д принтере. 

```
- Бортик выше/прозрачный колпак; защита от вылета шарика.
```

Крышка из поликарбоната рассмотрена выше в разделе про безопасность.
