# tachdraw fix10l — чертежи изготавливаемых деталей по STEP

Пакет чертежей деталей «орочьей» версии `fix10l`, требующих
изготовления. Для каждой — **один лист A4 портрет**, масштаб **1:2**,
две проекции, выход — **только PDF** (SVG/PNG не сохраняются).

## Комплект — 12 PDF

| Группа | Листы |
|---|---|
| Стол, подстолье, накладка | `06_table`, `11_podstol`, `07_overlay` |
| Отрезы труб | `12_B01`, `12_B02`, `13_B03`, `13_B04` |
| Уголки кронштейна | `27_bracket_left`, `27_bracket_right` |
| Кулачковый диск (ход 3/5/10) | `19_cam_3`, `19_cam_5`, `19_cam_10` |

Покупные детали (шпильки, гайки, шайбы, пружины, подшипники, U-болты,
саморезы, дрель) не чертились.

## STEP

- Индивидуальные STEP стола, подстолья, накладки, уголков и кулачков
  взяты из `../../cad/step` — в них уже есть все отверстия/вырезы.
- Для отрезов труб B01…B04 отдельных STEP не было: они выделены из
  групповых `12_beams_long.step` / `13_beams_trans.step` в
  `tachdraw/cad/B01.step` … `B04.step` **со всеми отверстиями**.
  B01 — с болтовым отверстием, B02 — без (по STEP; в `beam_cut.csv`
  у B02 указан болт — проверить).
- Проверенные признаки: стол — 18×Ø4,2 + 4×Ø11; подстолье —
  3×Ø11 + 4×Ø7; накладка — 4×Ø12 + 4×Ø4,2 + сфера Ø140; уголки —
  4×Ø4,2 + Ø10,5; кулачки — 8×Ø10 + шестигранник; B03/B04 —
  2×Ø11 + Ø10,2; B01/B02 — Ø11 по STEP.

## Размеры на листах

- габариты на каждой проекции;
- отверстия — **размерами на чертеже**: ординатами/цепями от
  левого/нижнего края, диаметры — выносками; таблиц координат нет;
- вырезы/элементы — размерными линиями или выноской с размером
  (сфера Ø140, шестигранник S17,1, буртик Ø40×10); у B01/B02
  диаметры — в примечании (тонкий длинный вид);
- примечания по материалу и допускам.

## Особенности

- **B01/B02** — 400 мм при 1:2 = 200 мм: лист компонуется вертикально;
  диаметры Ø11 указаны в примечании, позиции — ординатами.
- **Стол** — 18×Ø4,2 (в спецификации поз. 6 указано 4×Ø4,2 —
  остальные под пружины/уголки; в STEP все 18), 4×Ø11.
- **Кулачок** — 8×Ø10 на R32, шестигранник 17,1, буртик Ø40×10;
  боковой вид — силуэт.
- **Планка/пазы** в балках и уголках fix10l отсутствуют; вырезы —
  только сфера накладки и шестигранник кулачка.

## Запуск

```bash
cd stages/fix10l/tachdraw
freecadcmd -c "p='batch.py'; g={'__name__':'__main__','__file__':p}; \
exec(compile(open(p).read(), p, 'exec'), g)"
```

Один лист: `TACHDRAW_ONLY=12_B01` перед командой.

## Ограничения

- скрытые линии не строятся — отверстия показаны в видимом виде;
- для стола (22 отверстия) — плотная цепная схема от края;
- допуски/шероховатость — примечаниями;
- масштаб 1:2, A4 портрет.
