# tachdraw — чертежи деталей fix11 по STEP (A4, PDF)

Пакет чертежей деталей, **требующих изготовления**, этапа `fix11`.
Для каждой детали — **один лист A4 в портретной ориентации**, масштаб
**1:2**, две проекции, выход — **только PDF** (SVG/PNG не сохраняются).

Исходник — STEP-модель. Контур, отверстия и вырезы берутся из тела
(`Part.read` + `Drawing.project` + разбор цилиндрических граней).
Индивидуальные STEP отрезков дополнены всеми отверстиями и прорезями:
для T01…T18 берётся пересечение STEP рамы с габаритом отрезка
(`build.py` экспортирует именно такие тела). Чертежи используют эти
STEP напрямую.

## Комплект — 28 PDF

| Группа | Листы |
|---|---|
| Направляющие валы | `02_shaft` |
| Стол, подстолье, накладка стола | `05_table`, `11_podstol`, `04_overlay` |
| Кронштейн и накладки балки | `06_bracket`, `14_angle` |
| Поджимная балка | `21_beam` |
| Кулачковый диск (ход 3/5/10) | `10_cam_3`, `10_cam_5`, `10_cam_10` |
| Отрезки труб до сварки | `22_T01` … `22_T18` (18 листов) |

Покупные детали (подшипники 6200/LMK10UU, пружины, винты, гайки, шайбы,
U-хомуты, шпильки-валы, кулачковые шайбы, резина, кожух) чертежами
**не оформлялись**. Направляющие валы теперь изготавливаются из прутка
Ø10 h6: резка + резьба M10×15, поэтому на них есть лист `02_shaft`.

## Что на каждом листе

- рамка и основная надпись A4 (185 × 55), масштаб **1:2**;
- две проекции; направления выбираются по видимым отверстиям/вырезам и
  габариту (длинные гладкие детали — боковой вид + торец);
- габаритные размеры на каждой проекции;
- **отверстия** — размерными линиями на чертеже: ординатами/цепями
  от левого/нижнего края; диаметры — выносками (для цековок — оба
  диаметра); осевые линии на виде. Таблиц координат нет;
- **вырезы** — размерными линиями X1/X2/Y1/Y2 и шириной/высотой;
  паз кронштейна, седло T17/T18 и балка 21 — автоматически; для
  круглых/шестигранных углублений — центр + Ø/размер (например,
  Ø140, Ø8×5, 7,2×5, Ø12×3, S17,1) без координатной таблицы;
- примечания по материалу, печати, крепежу и допускам.

Особые случаи:

- **02_shaft** — вал Ø10 h6, L=176, резьба M10×15 на обоих концах;
  главный вид 1:2, деталь А 2:1, гайка M10 + шайба Ø18 — в примечании;
- **T01/T02** — 2×Ø4,5; **T07…T10** — 3×Ø4,5; **T11/T12** — 4×Ø6,6;
- **T13/T14** — 2×Ø10 в верхней стенке;
- **T15/T16** — 2×Ø10,5 сквозь + 3×Ø4,5;
- **T17/T18** — прорезь R15, ширина 9,4, глубина 5 + 2×Ø10,5;
- **21_beam** — отдельный лист `tachdraw.py` (размерные линии, а не
  таблица).

## Запуск

Из `stages/fix11/tachdraw`:

```bash
freecadcmd -c "p='batch.py'; g={'__name__':'__main__','__file__':p}; \
exec(compile(open(p).read(), p, 'exec'), g)"
```

Один лист:

```bash
TACHDRAW_ONLY=22_T13 freecadcmd -c "p='batch.py'; \
g={'__name__':'__main__','__file__':p}; \
exec(compile(open(p).read(), p, 'exec'), g)"
```

Только балка 21 (или `TACHDRAW_ONLY=21_beam` в batch.py):

```bash
freecadcmd -c "p='tachdraw.py'; g={'__name__':'__main__','__file__':p}; \
exec(compile(open(p).read(), p, 'exec'), g)"
```

## Ограничения

1. **Скрытые линии не строятся** — `Drawing.project` даёт только
   видимые рёбра. Отверстия показаны в том виде, где они видны, и
   размерами на чертеже; пунктиром не дорисовываются.
2. **Плотная компоновка стола.** Для 26 отверстий/углублений
   применены цепные размеры от левого/нижнего края; для круговых
   углублений — центр + Ø. Таблицы координат нет.
3. **Кулачок:** боковой вид — выпуклая оболочка проекции (фасеточная
   поверхность STEP даёт сотни рёбер); буртик Ø40×10 и шестигранник
   показаны примечанием. Для производства нужен отдельный профильный
   чертёж/сечение.
4. **Модель и спецификация расходятся:**
   - кронштейн 6: STEP 42×40×20×2, спецификация 40×40×20×2;
   - накладка 14: STEP 55×50, спецификация 50×50.
   На листах стоят размеры по STEP и примечание «проверить».
5. Масштаб жёстко 1:2. Для T07/T08 (360 мм) лист компонуется
   вертикально: на A4 при 1:2 это 180 мм.
6. Допуски/шероховатость — только примечаниями.
