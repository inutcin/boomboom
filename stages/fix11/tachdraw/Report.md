# Отчёт: tachdraw — чертежи изготавливаемых деталей fix11 по STEP

Дата: 2026-11-04
Этап: [`stages/fix11`](../README.md)
Каталог: `stages/fix11/tachdraw`
Промпт: [`techdraw_prompt.md`](./techdraw_prompt.md)

## 1. Задача

Создать в `fix11` каталог `tachdraw`; для каждой детали, взяв исходник
STEP, сделать чертёж:

- один лист **A4 портрет**, рамка с основной надписью, масштаб **1:2**;
- две наиболее подходящие проекции;
- размеры габаритов, расстояний от краёв до центров отверстий и
  диаметров отверстий, расстояний от краёв до кромок вырезов;
- выход — **только PDF** (SVG/PNG не нужны).

Чертежи — **только для деталей, требующих изготовления**:

- отрезки труб до сварки, включая отверстия и прорези;
- стол, подстолье, накладка стола;
- уголки кронштейна, накладки на поджимную балку;
- поджимная балка;
- кулачковый диск.

Покупные детали не чертятся.

## 2. Что сделано

### 2.1. Комплект — 27 PDF

| Группа | Листы |
|---|---|
| Стол / подстолье / накладка | `05_table`, `11_podstol`, `04_overlay` |
| Уголки и накладки | `06_bracket`, `14_angle` |
| Поджимная балка | `21_beam` |
| Кулачковый диск | `10_cam_3`, `10_cam_5`, `10_cam_10` |
| Отрезки труб до сварки | `22_T01` … `22_T18` (18 листов) |

Все — A4 портрет (595,3 × 841,9 pt), по одной странице, М 1:2.
Покупные детали (6200, LMK10UU, пружины, ограничители, винты/гайки/
шайбы, U-хомуты, шпильки, резина, кожух) не оформлялись.

### 2.2. Метод

`batch.py` для каждой детали:

1. читает STEP (`Part.read`); для группы берёт нужное тело (`pick`);
2. находит полные вогнутые цилиндры — отверстия (R, ось, центр);
   частичные вогнутые цилиндры — вырезы/седла;
3. выбирает две проекции по числу видимых отверстий/вырезов и
   габариту; для длинных гладких деталей — боковой вид + торец;
4. раскладывает виды на A4 (длинные — вертикально), ставит габариты;
5. наносит **размеры отверстий прямо на чертёж**: ординаты/цепи от
   левого/нижнего края, диаметры — выносками (для цековок — оба
   диаметра); таблиц координат нет;
6. вырезы — размерными линиями X1/X2/Y1/Y2 и W/H: паз кронштейна и
   седло T17/T18 автоматически по проекции; балка 21 — размерными
   линиями; для круглых/шестигранных углублений — центр + Ø/размер
   (Ø140, Ø8×5, 7,2×5, Ø12×3, S17,1);
7. выводит PDF через `cairosvg` (SVG в памяти).

### 2.3. Отрезки труб

Все `T01…T18` — индивидуальные STEP, в которые при экспорте внесены
**все отверстия и прорези** (пересечение STEP рамы с габаритом отрезка;
`build.py` теперь экспортирует именно такие тела). Состав:

- T01/T02 — 2×Ø4,5;
- T07/T08, T09/T10 — 3×Ø4,5;
- T11/T12 — 4×Ø6,6;
- T13/T14 — 2×Ø10 в верхней стенке;
- T15/T16 — 2×Ø10,5 сквозь + 3×Ø4,5;
- T17/T18 — прорезь R15 (9,4×5) + 2×Ø10,5.

`tube_cut.csv` обновлён теми же примечаниями.

### 2.4. Особые листы

- **21_beam** — отдельный лист `tachdraw.py`: размерные линии (9,8 /
  24,8, 39,8 / 80 / 39,8, 68,62 / 22,36 / 68,62), Ø10/Ø4,5, R15/5;
- **10_cam_*** — три варианта хода 3/5/10; 8×Ø10 на R32, шестигранник
  17,1, буртик Ø40×10, ложбинка 1…2 мм;
- **05_table** — 26 отверстий/углублений (Ø4,2; Ø5; Ø5/8; Ø11),
  4 шестигранных углубления 7,2×5 и 2×Ø8×5; на виде — цепные размеры
  от края и диаметровые выноски;
- **11_podstol** — 8×Ø6,6 (4 M6 с зенковкой Ø12×3 + 4 под U-хомут);
- **06_bracket** — паз 10×5 и Ø10,1;
- **14_angle** — 2×Ø4,5, ширина 25, t=2.

## 4. Найденные расхождения

1. **Кронштейн 6.** STEP: 42×40×20×2; спецификация: 40×40×20×2.
   На листе — 42 по STEP и примечание «спец. 40×40 — проверить».
2. **Накладка-уголок 14.** STEP: 55×50; спецификация: 50×50.
   На листе — 55 по STEP и примечание «спец. 50×50 — проверить».
3. **Отрезки труб.** Индивидуальные STEP дополнены всеми
   отверстиями/прорезями из рамы; `tube_cut.csv` обновлён. Отверстия
   Ø10,5 в T15…T18 и Ø4,5 в T01/T02, T07…T10, T15/T16 показаны на
   чертежах размерами и Ø-выносками.
4. **Кулачок.** Боковой вид — выпуклая оболочка (фасеточная
   поверхность STEP даёт сотни рёбер); для производства нужен
   отдельный профильный чертёж/сечение.

## 5. Ограничения

- скрытые линии не строятся — отверстия показаны только в видимом
  виде и размерами;
- для стола (26 отверстий) — плотная цепная размерная схема; для
  круглых углублений размер задан центром и Ø (без координатной
  таблицы);
- допуски/шероховатость — только примечаниями;
- масштаб 1:2; T07/T08 (360 мм) компонуются вертикально;
- покупные детали не чертились (по условию).

## 6. Воспроизведение

```bash
cd stages/fix11/tachdraw
freecadcmd -c "p='batch.py'; g={'__name__':'__main__','__file__':p}; \
exec(compile(open(p).read(), p, 'exec'), g)"
```

Один лист: `TACHDRAW_ONLY=22_T13` перед командой.
Балка отдельно: `TACHDRAW_ONLY=21_beam` (или `tachdraw.py`).
