# Третье устранение замечаний по первоначальной версии модели 

Повторно доработать модель после первой доработки согласно замечаниям.

С учетом замечаний ниже сделать.

- 3D модель в установленном формате 
- эскиз в 3 проекциях: вид сбоку и вид слева
- трёхмерное изображение конструкции.
- спецификацию деталей
 
## Замечания

1. На подстолье сделай обычные болты, а не потайные.

2. Убери лишние поперечные балки в выносе, об них будут стучаться подшипники. 
На выносе в принципе не нужны никакие поперечины, их роль выполняет подстолье.

3. Убери рёбра на подстолье, они мешают крепить дрель. Ничего страшного если 
оно будет слегка прогибаться под дрелью. Вертикальные нагрузки там небольшие.

4. Крепление балки фиксации подшипников - верни вариант с плоскими уголками 
как в папке как в папке fix1, только:
- убери уголки с верхней грани балки
- уголок на передней грани балки разверни так, чтобы он смотрел вниз
- добавь уголки, крепящие заднюю грань балки к стойкам

5. Бортик выемки на кулачковом диске сделать не прямым, а скошенным, во первых 
для облегчения печати, во вторых для того, чтоб ролик самоцентрировался при 
вращении в диске. Внетреннее отверстие должно иметь закреглённую фаску для
плотного контакта с конусной гайкой. Предусмотреть 6 отверстий по радиусу для
облегчения диска. 

6. Отверстия под валы должны быть больше в диаметре на 1 мм в столе и на 2 мм 
в накладке, чтобы вал не касался их при колебаниях вверх-вниз

7. Уменьшить глубину рамы виброблока, для сокращения длины вала между опорными
подшипниками и уменьшения его изгиба под действием пружины. Соответствующе
уменьшить продольный размер стола и длину вала основного привода. Уменьшение
составляет 40mm. Пересчтитать стол, подстолье, крепление кронштейнов, отверстия
под валы, размещение динейных подшипников и всего, что будет затронуто.
