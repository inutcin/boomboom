# Третья корректировка после инженерной экспертизы

С учётом замечаний ниже сделать:

- 3D-модель в установленном формате;
- эскиз в трёх проекциях (вид сбоку, вид слева, вид сверху);
- трёхмерное изображение конструкции;
- спецификацию деталей.

# Замечания

1. Оба подшипника подвески оснвного вала привода должны поджиматься с боков
коническими подшипинками, которае должны контриться гайками M10.

# Результаты этапа

База: [`stages/fix5`](../fix5/README.md). Выполнено замечание 1: у обоих
опорных 6200 вала привода (X=10 и X=150) исправлен и проверен осевой зажим —
по два конуса Ø12→Ø16×5,5 на каждый подшипник (по одному с каждой стороны)
и по одной контргайке M10 nyloc снаружи каждого конуса. В fix5 левая
контргайка 6200 №2 стояла поверх конуса
(137,5…145,5 вместо 132…140, пересечение 403 мм³); теперь стек строится от
центра подшипника, пересечений нет.
