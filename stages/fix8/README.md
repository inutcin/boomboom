# Первая корректировка после третьей инженерной экспертизы

База: [`stages/fix7`](../fix7/README.md). Выполнено выбранное в третьей
экспертизе оптимальное решение для **размаха (peak-to-peak)** 3/5/10 мм:
пружина **4×Ø17×1,5×60, 9 активных витков**. Остальные замечания expert2 /
expert3 в этом этапе **не выполнялись**.

## Замечание

Заменить пружины fix7 (4×Ø12×1,0 L0=70) на оптимальную пружину для режимов
5/10/15 Гц × 3/5/10 мм (размах), выбранную в
[`../expert3/optimum.md`](../expert3/optimum.md):

- Ø17 мм, проволока 1,5 мм, свободная длина 60 мм;
- 9 активных витков (11 полных), закрытые шлифованные концы;
- 4 шт.; установленная длина 36 мм; шайбы Ø18/Ø10,5×1,5 — существующие.
