Дата: 2026-10-30
Этап: `stages/fix8`
База: [`stages/fix7`](../fix7/README.md)
Инструменты: FreeCAD 0.19 (`Part`, `Drawing`/HLR), Blender 3.0.1 (EEVEE),
Python 3.10, cairosvg.

**размаха (peak-to-peak)** 3/5/10 мм. Остальные замечания expert2/expert3 не
выполнялись.

## 6. Ограничения

- Выполнена только замена пружин; C1–C8, I1–I23, W1–W8 expert2 и S1–S6
  expert3 (кроме выбора пружины) не выполнялись.
- Расчёт контакта — квазистатический, без удара шарика/динамики рамы;
  напряжения — по Wahl, допускаемое 500…700 МПа — ориентировочное.
- Пружина покупная; в модели показана установленная (36 мм), свободная 60 мм
  задана в спецификации/расчёте. Реальные k/L0/ID нужно проверить.
- Для нуль-пик 3/5/10 мм (размах 6/10/20) этот вариант не подходит; см.
  [`../expert3/optim-pick-pick.md`](../expert3/optim-pick-pick.md).
- Остаётся предупреждение по стенке 3 мм у R32 на диске 10.

## 7. Воспроизведение

```bash
cd stages/fix8/cad
freecadcmd build.py
freecadcmd draw_sheet.py
freecadcmd export_groups.py
blender -b --python render_views.py
cd ..
python3 - <<'PY'
import cairosvg
for n in ("vibrotable_views", "vibrotable_spec", "iso", "iso_open"):
    cairosvg.svg2png(url=f"fig/{n}.svg", write_to=f"pic/{n}.png", dpi=110)
PY
```
